# Ownership is permanent; only a Reset changes the Owner

Ada is meant to become an intimate confidant of one person, someone the Owner talks to about ideas and worries as they would a close friend. A transferable bond would undercut that, so there is no handover: the only way for Ada to have a different Owner is a Reset, which erases everything she has learned and returns her to first-boot setup. A gifted or inherited device therefore always starts from nothing. This may be revisited in a later version.
