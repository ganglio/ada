# Voice weights and gates conversation; consequential actions go through Telegram

A voice can be imitated by a recording or a visitor, and everyone in the room hears what Ada says aloud. Voice recognition is therefore a weak signal: it sets a speaker's Standing-weighted influence and gates conversation, but cannot authorise anything lasting. Changing Standing, forgetting everything, pinning Memories and answering Help requests need the Owner's confirmation over Telegram, which reaches only the Owner, so sensitive answers are given there with full attribution while voice answers stay narrow. Reset is deliberately outside both channels: it can only be run on the host machine's command line.

## Consequences

Housemates and Friends have no Telegram access in v1. If the Owner loses their phone, Telegram's own account security is the only barrier to what Ada knows.
