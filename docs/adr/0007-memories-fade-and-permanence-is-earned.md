# Memories fade, permanence is earned, and no one is forgotten on command

Ada is meant to remember the way a person does: what is not reinforced fades, what keeps coming up across many Conversations over months becomes permanent, and people are never erased on request. A recognised person can ask her to forget specific things they said, which deletes that speech and any Memory that came only from it, but there is no "forget a person" command, and "forget that" is not meant to be used as an interjection to disrupt her learning. Code counts the reinforcement and promotes a Memory; the model only judges whether two mentions are the same fact. The Owner can still correct or delete anything, permanent Memories included.

## Consequences

An always-listening companion that will not forget someone on request is a deliberate privacy trade-off, accepted because Ada's value is in being a continuous presence. Because the Owner can see and delete everything and every Segment expires, the exposure is bounded.
